# OOP Bank Account

A Python-based command-line banking system developed using Object-Oriented Programming (OOP). The project manages bank account operations and records transaction history in a CSV file. Pandas is used to analyze the transaction dataset.

## Features

- Create a bank account
- Store account holder details
- Set an initial account balance
- Deposit money
- Withdraw money
- Check current balance
- Record transaction history
- View transaction history
- Analyze transactions using pandas
- Validate user input
- Prevent withdrawal when the balance is insufficient

## Technologies Used

- Python 3
- Pandas
- CSV
- Object-Oriented Programming
